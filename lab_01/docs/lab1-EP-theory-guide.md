## 1. Что делаем в первой лабе

Разрабатываем **имитационную модель** одноканальной разомкнутой СМО (системы массового обслуживания).

Структура системы:
- **2 генератора заявок** (тип 1 — высокий приоритет, тип 2 — низкий приоритет)
- **1 обслуживающий аппарат** (канал)
- **Буфер бесконечной ёмкости** (очередь не ограничена)

Типы заявок отличаются только **параметрами** законов распределения — сами законы одинаковые для обоих типов.

### Вариант 11

| | Закон поступления (интервалы между заявками) | Закон обслуживания |
|---|---|---|
| Тип 1 | Нормальный (λ₁ = 1.5, σ₁ = 0.15) | Экспоненциальный (μ₁ = 8.0) |
| Тип 2 | Нормальный (λ₂ = 2.0, σ₂ = 0.12) | Экспоненциальный (μ₂ = 10.0) |

Здесь λ — интенсивность поступления (среднее значение для нормального закона), σ — среднеквадратическое отклонение, μ — интенсивность обслуживания.

### Дисциплина обслуживания

Возможны три варианта (выбирается при выдаче задания):
1. **Бесприоритетная** — FIFO, кто первый пришёл, тот первый обслужен.
2. **С относительными приоритетами** — заявки типа 1 встают в очередь перед заявками типа 2, но **не прерывают** текущее обслуживание. (Наш вариант.)
3. **С абсолютными приоритетами** — заявки типа 1 **прерывают** обслуживание заявки типа 2 (та возвращается в очередь).

### Что программа должна делать

1. Принимать от пользователя: интенсивности поступления (λ₁, λ₂), разброс (σ₁, σ₂), интенсивности обслуживания (μ₁, μ₂).
2. Выводить **расчётную (теоретическую)** загрузку: ρ = λ₁/μ₁ + λ₂/μ₂.
3. Выводить **фактическую** загрузку по результатам моделирования.
4. Давать возможность задавать условие окончания моделирования (по времени, по числу обслуженных, по числу сгенерированных).
5. Строить графики зависимостей.

## 2. Какая модель используется

**Имитационная модель** — мы не решаем систему аналитически, а моделируем (симулируем) каждое событие: приход заявки, начало обслуживания, окончание обслуживания.

### Имитационная vs аналитическая модель

| | Имитационная | Аналитическая |
|---|---|---|
| Суть | Воспроизводим процесс пошагово, используя генератор случайных чисел | Записываем математические формулы (Эрланг, Поллачек-Хинчин и т.д.) |
| Точность | Зависит от числа прогонов (чем больше — тем точнее) | Точное решение (если модель корректна) |
| Гибкость | Можно моделировать практически любую систему | Только для систем с известным аналитическим решением |
| Скорость | Медленнее (нужно много прогонов) | Мгновенный расчёт |
| Когда используется | Сложные системы, нестандартные дисциплины | Простые, хорошо изученные системы |

В лабах 1–4 используется **имитационная** модель.

### Принцип моделирования

**Событийный** (event-driven). Модель перескакивает от одного события к следующему по времени, а не тикает с фиксированным шагом. События: приход заявки, окончание обслуживания.

## 3. Классификация моделируемой системы

Перед исследованием системы нужно определить:

1. **Класс системы**: наша СМО — **динамическая** (состояние меняется во времени) и **стохастическая** (содержит случайные величины — интервалы поступления и времена обслуживания).
2. **Режим работы**: нас интересует **стационарный (установившийся)** режим — когда очередь и время ожидания не растут бесконечно. Это возможно только при загрузке ρ < 1.
3. **Промежуток наблюдения**: достаточно длительный, чтобы система вышла на стационарный режим (в нашем случае — 10 000 обслуженных заявок).
4. **Объём испытаний**: сколько повторных экспериментов нужно для статистической достоверности (у нас — 5 прогонов на точку, результаты усредняются).

## 4. Пассивный и активный эксперимент

### Какой опыт проводили в лабе 1?

**Пассивный.**

### В чём разница

**Пассивный эксперимент** — ставится большая серия опытов с **поочерёдным** варьированием каждой из переменных. Мы меняем один фактор (например λ₁), фиксируя остальные, и смотрим, как меняется выходной параметр. Это именно то, что делается в лабе 1 при построении графиков: поочерёдно варьируем λ₁, λ₂, μ₁, μ₂.

**Активный эксперимент** — ставится по заранее составленному плану, при этом предусматривается **одновременное** изменение всех параметров. Это позволяет:
- установить **силу взаимодействия** параметров;
- сократить общее число опытов.

Обработка данных в обоих случаях ведётся методами **корреляционного и регрессионного анализа**.

### Как планировали эксперимент в лабе 1?

**Не планировали.** Планирование эксперимента — это процедура активного эксперимента. В лабе 1 мы проводим пассивный эксперимент: просто варьируем параметры по одному и наблюдаем результат.

### Преимущества активного эксперимента

- Возможность предсказания количества опытов, которые следует провести.
- Определение точек факторного пространства, где следует проводить опыты.
- Отсутствие проблем, связанных с выбором вида уравнения регрессии.
- Возможность определения оптимальных параметров экспериментально-статистическим методом.
- Сокращение объёма опытных исследований.

2. **Повышение информативности** каждого из экспериментов в отдельности.

## 6. Стационарный режим

**Стационарный режим** — состояние системы, при котором:
- очередь не растёт бесконечно;
- время ожидания не растёт бесконечно;
- загрузка системы находится в интервале **0 < ρ < 1**.

Если ρ ≥ 1 — система перегружена, очередь растёт неограниченно, стационарного режима нет.

Для нашей одноканальной СМО: **ρ = λ₁/μ₁ + λ₂/μ₂**. При параметрах варианта 11: ρ = 1.5/8.0 + 2.0/10.0 = 0.1875 + 0.2 = 0.3875 — система работает в стационарном режиме с большим запасом.

## 7. Графики

### Зачем нужен график

**Главный вопрос по лабе:** за счёт графика определяем **вид уравнения регрессии** — функциональную зависимость y(x), по которой для любого значения x можно определить значение y.

Ответ «для сравнения теоретического и фактического значения» — **неправильный**. Правильный ответ: по графику эмпирической линии регрессии (построенной по экспериментальным данным) определяется **характер зависимости** — какая она: линейная, полиномиальная, экспоненциальная и т.д.

Обычно в диапазоне загрузки **от 0 до 0.5–0.6** зависимость выглядит **линейной**. Это знание понадобится в последующих лабах (для выбора вида уравнения регрессии при планировании активного эксперимента).

### Какие графики строим (6 штук)

Выходной параметр: **среднее время ожидания (пребывания)** для каждого типа заявок.

1. **y(R)** — зависимость от общей загрузки системы R (λ₁ и λ₂ варьируются пропорционально).
2. **y(ρ₁)** — зависимость от частной загрузки ρ₁ = λ₁/μ₁ (λ₂ фиксирована).
3. **y(λ₁)** — зависимость от интенсивности поступления заявок типа 1.
4. **y(λ₂)** — зависимость от интенсивности поступления заявок типа 2.
5. **y(μ₁)** — зависимость от интенсивности обслуживания заявок типа 1.
6. **y(μ₂)** — зависимость от интенсивности обслуживания заявок типа 2.

На каждом графике — **две кривые**: для типа 1 (высокий приоритет) и типа 2 (низкий приоритет).

### Откуда начинается график

Время пребывания начинается **с величины порядка 1/μ** (т.е. со времени обслуживания), а не с нуля. При нулевой загрузке ожидания нет, заявка сразу идёт на обслуживание, поэтому время пребывания = время обслуживания. Если интенсивность обслуживания μ = 1, то время пребывания начинается с 1.

### Почему график может быть пологим

Зависит от выбранных законов распределения. При **нормальном** законе поступления (наш случай) график пологий, потому что нормальное распределение с малой дисперсией даёт стабильные интервалы между заявками — система ведёт себя предсказуемо, без резких всплесков очереди.

### Что делать с нелинейным участком графика (ρ > 0.5–0.6)

Когда зависимость перестаёт быть линейной, можно:
- Выразить кривую как **ломаную** и рассматривать каждый кусочек отдельно (кусочно-линейная аппроксимация).
- Это самый простой способ.

### Как сгладить ломаный график

- Взять **меньший шаг** по x (посчитать больше точек).
- **Усреднять** несколько прогонов в каждой точке (в нашей программе — 5 прогонов на точку).
- Использовать **полиномиальную аппроксимацию** (в программе — полином 7 степени по 100 точкам).
- Интерполяция (ответ допустимый, но не приветствуется преподавателем).

## 8. Что в результате опытов должны получить

Информацию **об объекте** — о поведении СМО при различных параметрах. Конкретно: как зависит среднее время ожидания/пребывания от загрузки и отдельных параметров, и определить вид этой зависимости (уравнение регрессии).

## 9. Ключевые определения

| Термин | Определение |
|---|---|
| **Эксперимент** | Система операций, воздействий и/или наблюдений, направленных на получение информации об объекте при исследовательских испытаниях |

| **Уровень фактора** | Фиксированное значение фактора относительно начала отсчёта |
| **Основной уровень фактора** | Натуральное значение фактора, соответствующее нулю в безразмерной шкале |

| **Эффект взаимодействия факторов** | Показатель зависимости изменения эффекта одного фактора от уровней других факторов |
| **Факторное пространство** | Пространство, координатные оси которого соответствуют значениям факторов |
| **Область экспериментирования** | Область факторного пространства, где могут размещаться точки, отвечающие условиям проведения опытов |
