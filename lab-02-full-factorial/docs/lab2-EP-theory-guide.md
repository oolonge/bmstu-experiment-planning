## 1. Что мы делаем

В лабе 1 мы проводили **пассивный эксперимент** — меняли параметры по одному и смотрели, как меняется выход. Это давало графики зависимостей, но не давало формулы.

В лабе 2 мы проводим **активный эксперимент** — полный факторный эксперимент (ПФЭ). Его результат — **уравнение регрессии**: формула, которая предсказывает выходную величину по входным параметрам.

**Задача**: составить матрицу планирования ПФЭ 2⁶ для одноканальной СМО с двумя типами заявок, провести 64 эксперимента, получить линейную и частично нелинейную регрессию.

---

## 2. Терминология

### Базовые понятия

| Термин | Что значит |
|---|---|
| **Фактор** | Входной параметр, который мы варьируем (λ₁, σ₁, μ₁, λ₂, σ₂, μ₂) |
| **Отклик (y)** | Выходная величина — то, что мы измеряем (среднее время ожидания) |
| **Уровень фактора** | Конкретное значение фактора в эксперименте |
| **Основной уровень (x₀)** | Центральное значение фактора: x₀ = (x_max + x_min) / 2 |
| **Интервал варьирования (Δ)** | Половина размаха: Δ = (x_max − x_min) / 2 |
| **Кодированное значение** | Безразмерная шкала: −1 (минимум) и +1 (максимум) |
| **Нормализация** | Перевод натуральных значений в кодированные: z = (x − x₀) / Δ |
| **Матрица планирования** | Таблица, где каждая строка — один эксперимент, каждый столбец — фактор |
| **Уравнение регрессии** | Формула ŷ = f(x₁, x₂, ...), аппроксимирующая зависимость отклика от факторов |

### Что такое ПФЭ

**Полный факторный эксперимент (ПФЭ)** типа 2ⁿ — это эксперимент, в котором:
- **2** — число уровней каждого фактора (минимум и максимум, закодированные как −1 и +1);
- **n** — число факторов;
- **2ⁿ** — число экспериментов (все возможные комбинации уровней).

У нас 6 факторов → ПФЭ 2⁶ = **64 эксперимента**.

### Почему именно 2 уровня

Для построения **линейной** модели (гиперплоскости) по каждому фактору достаточно двух точек — прямая определяется двумя точками. А берём мы крайние значения (−1 и +1), потому что чем шире «плечо», тем точнее определяется наклон прямой (минимизируется дисперсия оценки коэффициентов).

## 3. Матрица планирования

### Структура

Для 2 факторов матрица выглядит так:

| № опыта | x₀ | x₁ | x₂ | y |
|---|---|---|---|---|
| 1 | +1 | −1 | −1 | y₁ |
| 2 | +1 | +1 | −1 | y₂ |
| 3 | +1 | −1 | +1 | y₃ |
| 4 | +1 | +1 | +1 | y₄ |

Столбец x₀ — фиктивный (всегда +1), нужен для расчёта свободного члена b₀.

Для 6 факторов — 64 строки, каждая строка — уникальная комбинация ±1 для шести факторов.

### Свойства матрицы планирования

1. **Симметричность**: сумма элементов каждого столбца = 0 (кроме x₀).
   Σxᵢⱼ = 0 → центр плана совпадает с началом координат.

2. **Нормировка**: сумма квадратов элементов каждого столбца = N (число опытов).
   Σxᵢⱼ² = N

3. **Ортогональность**: скалярное произведение любых двух разных столбцов = 0.
   Σxᵢⱼ · xᵢₖ = 0 при j ≠ k

4. **Ротатабельность**: точность предсказания одинакова на равных расстояниях от центра плана.

### Почему ортогональность важна

Благодаря ортогональности матрица XᵀX становится **диагональной**. Это значит:
- Коэффициенты регрессии **независимы** друг от друга.
- Каждый коэффициент вычисляется **отдельно** по простой формуле.
- Можно **добавлять или убирать** столбцы (факторы) без пересчёта остальных коэффициентов.

---

## 4. Нормализация (кодирование) факторов

Натуральные значения переводятся в кодированные по формуле:

```
zⱼ = (xⱼ − x₀ⱼ) / Δxⱼ
```

где:
- xⱼ — натуральное значение фактора
- x₀ⱼ = (x_max + x_min) / 2 — основной уровень (центр)
- Δxⱼ = (x_max − x_min) / 2 — интервал варьирования

На границах области: zⱼ = ±1, в центре: zⱼ = 0.

### Пример для нашего варианта (λ₁)

- x_min = 1.2, x_max = 1.8 (из лабы 1: λ₁ = 1.5 ± 0.3)
- x₀ = (1.2 + 1.8) / 2 = 1.5
- Δ = (1.8 − 1.2) / 2 = 0.3
- При λ₁ = 1.2: z = (1.2 − 1.5) / 0.3 = −1
- При λ₁ = 1.8: z = (1.8 − 1.5) / 0.3 = +1

## 5. Вычисление коэффициентов регрессии

### Линейная модель

```
ŷ = b₀ + b₁z₁ + b₂z₂ + ... + b₆z₆
```

Благодаря ортогональности матрицы, коэффициенты вычисляются по формуле **МНК (метод наименьших квадратов)**:

```
bⱼ = (1/N) · Σᵢ(zᵢⱼ · yᵢ),  j = 0, 1, ..., m
```

где N = 2⁶ = 64 — число экспериментов.

- **b₀** = среднее арифметическое всех откликов (т.к. z₀ₖ = +1 для всех строк).
- **bⱼ** показывает **силу влияния** фактора j: чем больше |bⱼ|, тем сильнее фактор.

### Частично нелинейная модель (с парными взаимодействиями)

```
ŷ = b₀ + Σ bⱼzⱼ + Σ bⱼₖ · zⱼ · zₖ    (j < k)
```

Коэффициенты взаимодействий:

```
bⱼₖ = (1/N) · Σᵢ(zᵢⱼ · zᵢₖ · yᵢ)
```

Столбец для взаимодействия zⱼ·zₖ — это **поэлементное произведение** столбцов zⱼ и zₖ. Он тоже ортогонален всем остальным столбцам → коэффициент вычисляется независимо.

Для 6 факторов парных взаимодействий: C(6,2) = **15 штук**.

Итого: линейная модель имеет **7 коэффициентов** (b₀ + 6), нелинейная — **22 коэффициента** (7 + 15).

---

## 6. Переход от нормированных к натуральным переменным

Подставляем в уравнение обратную формулу zⱼ = (xⱼ − x₀ⱼ) / Δⱼ и раскрываем скобки.

### Для линейной модели

```
ŷ = b₀ + Σ bⱼ · (xⱼ − x₀ⱼ)/Δⱼ
  = (b₀ − Σ bⱼ·x₀ⱼ/Δⱼ) + Σ (bⱼ/Δⱼ) · xⱼ
```

Натуральные коэффициенты:
- a₀ = b₀ − Σ(bⱼ · x₀ⱼ / Δⱼ)
- aⱼ = bⱼ / Δⱼ

### Для нелинейной модели

При раскрытии произведений zⱼ·zₖ = ((xⱼ − x₀ⱼ)/Δⱼ)·((xₖ − x₀ₖ)/Δₖ) появляются перекрёстные члены, которые добавляют вклад во **все** коэффициенты — поэтому натуральные коэффициенты отличаются от простого деления на Δ.

### Почему в нормированных коэффициенты не пересчитываются, а в натуральных — да

В нормированных переменных коэффициенты **независимы** (ортогональность). Добавление нового члена (например, взаимодействия) не меняет уже посчитанные bⱼ.

В натуральных переменных при раскрытии скобок произведение zⱼ·zₖ порождает члены с xⱼ, xₖ и свободный член → все натуральные коэффициенты меняются.

---

## 7. Что показывают коэффициенты

- **b₀** — значение отклика в центре плана (при всех zⱼ = 0).
- **bⱼ** — вклад фактора j в отклик. Чем больше |bⱼ|, тем сильнее этот фактор влияет.
- **bⱼₖ** — эффект **взаимодействия** факторов j и k. Если bⱼₖ ≠ 0, то влияние фактора j зависит от уровня фактора k (и наоборот).

---

## 8. Сравнение с реальным значением

Чтобы проверить качество модели:
1. Подставляем кодированные значения факторов в уравнение → получаем **предсказанное** ŷ.
2. Запускаем моделирование с теми же параметрами → получаем **реальное** y.
3. Считаем **погрешность**: |Δ| = |ŷ − y|.

Это делается:
- Для **всех 64 точек** плана (таблица с погрешностями).
- Для **центра плана** (все zⱼ = 0) — здесь ŷ = b₀ для обеих моделей.

Если в центре плана линейная и нелинейная модели дают **одинаковый** b₀, это **не гарантирует** совпадения в других точках. Геометрически: линейная модель — плоскость, нелинейная — гиперболический параболоид (седло), и они могут пересекаться только в центре.

## 10. Что происходит в программе (по шагам)

1. Пользователь задаёт для каждого фактора **центр** и **интервал** (или min/max).
2. Программа строит **матрицу планирования** 2⁶ = 64 строки.
3. Для каждой строки: переводит кодированные ±1 в натуральные значения → запускает моделирование СМО → получает отклик y.
4. По формулам МНК вычисляет **коэффициенты** линейной и нелинейной моделей.
5. Для каждой точки вычисляет **предсказания** обеих моделей и **погрешности**.
6. Записывает уравнения в **нормированных** и **натуральных** переменных.
7. Проверяет модель в **центре плана** — запускает моделирование с центральными параметрами и сравнивает с b₀.

## 11. Краткая сводка для защиты

1. **Что за эксперимент?** — Активный, полнофакторный, 2⁶.
2. **Что означает 2 и 6?** — 2 уровня (±1), 6 факторов.
3. **Почему в таблице только ±1?** — Нормализация: натуральные значения переводятся в безразмерную шкалу [−1, +1].
4. **Почему берём крайние точки?** — Максимальное «плечо» минимизирует дисперсию оценки коэффициентов.
5. **Свойства матрицы** — симметричность, нормировка, ортогональность, ротатабельность.
6. **Зачем ортогональность?** — XᵀX диагональна → коэффициенты независимы, можно добавлять/убирать без пересчёта.
7. **Почему нормированные коэффициенты не пересчитываются?** — Ортогональность. В натуральных — раскрытие скобок меняет все коэффициенты.
8. **Что показывают bⱼ?** — Силу влияния каждого фактора на отклик.
9. **Совпадение в центре = совпадение везде?** — Нет. Плоскость и седло пересекаются в одной точке.
10. **ПФЭ — это что?** — Все комбинации уровней всех факторов, N = 2ⁿ.
11. **Как проверить правильность?** — Сделать одинаковые входные параметры → коэффициенты должны совпасть.
12. **В чём удобство?** — Ортогональность позволяет спокойно добавлять новые столбцы (факторы взаимодействия) без пересчёта остальных.
